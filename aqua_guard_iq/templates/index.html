#include <WiFi.h>
#include <HTTPClient.h>

const char* serverUrl = "http://192.168.1.100:5000/api/sensor-data";
const char* apiKey    = "AG-IQ-••••••••-2026"; // Configured via SENSOR_API_KEY environment variable

void sendTelemetry(float litres, float flowRateLpm, float tdsPpm) {
  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;
    http.begin(serverUrl);
    http.addHeader("Content-Type", "application/json");
    http.addHeader("X-Sensor-API-Key", apiKey);

    String payload = "{\"device_id\":\"ESP32_TEST\",\"litres_flowed\":" + 
      String(litres, 2) + ",\"flow_rate_lpm\":" + 
      String(flowRateLpm, 2) + ",\"tds_ppm\":" + 
      String(tdsPpm, 1) + "}";

    int httpCode = http.POST(payload);
    Serial.printf("[HTTP] POST Code: %d\n", httpCode);
    http.end();
  }
}

🔬 Predictive Maintenance & Degradation Mathematics

1. Base Degradation Dynamics CORE ENGINE
Effective Wear = Raw Volume × K_TDS × K_Flow

Replaces raw volumetric depletion with physics-informed wear weighting. Every liter flowing through the RO cartridge is adjusted by mineral hardness and hydraulic velocity.

2. Hardness Factor ($K_{\text{TDS}}$)

Calibrated against purified municipal baseline water (250 PPM = 1.00). Mineral levels exceeding 250 PPM accelerate microscopic pore scaling:

K_TDS = 1.0 + max(0, (TDS - 250) / 500)

Example: Hard groundwater at 375 PPM yields $K_{\text{TDS}} = 1.25$ (a 25% acceleration in effective membrane pore exhaustion).

3. Turbulence Stress Factor ($K_{\text{Flow}}$)

High-velocity water dispensing generates hydrodynamic shear stress across delicate semi-permeable membranes. Flow rates $> 3.5\text{ L/min}$ induce a 1.15× multiplier:

K_Flow = 1.15 if flow_rate > 3.5 L/min else 1.00

Accounts for trans-membrane pressure surges and physical membrane flex fatigue during aggressive tap dispensing.

4. RUL Forecasting (Remaining Useful Life in Days)

Projected maintenance timelines are computed by dividing remaining capacity by the 7-day rolling exponentially smoothed burn rate:

RUL (Days) = floor(Remaining Capacity / 7-Day Rolling Daily Average)

Adaptive Exponential Smoothing: S_t = 0.30 × Usage_t + 0.70 × S_{t-1}

Eliminates false alert spikes caused by isolated single-day high usage events (e.g. weekend home cleaning).
